# 听见图表 · Hear Chart

**用声音探索图表，让数据不只被看见。**

面向视障、低视力学生的图表声音化前端原型：将数值转换为音高、将数据顺序映射到左右声道，配合键盘逐点浏览、语音朗读和规则摘要，帮助用户理解折线图与柱状图。

> 当前版本：**v0.1 原型**。初始代码和方案由 Claude 辅助产出；本仓库在此基础上完成了第一轮可靠性与无障碍迭代。样例数据均为虚构；尚未完成真实读屏用户验收，不代表已达到无障碍合规标准。

## 当前能做什么

- **听数据点**：方向键、Home / End、点击或触摸拖动图表，浏览每个标签和数值。
- **听整体变化**：折线连续滑音，柱状图逐点发声；数值对应约 220–880 Hz，顺序对应左右声道。极值会加高八度提示，穿过零点时有轻微点击声。
- **参考音**：播放整条前可先听最低音和最高音（默认开启，可在设置中关闭）。
- **暂停、续播与停止**：空格播放整条，再按一次暂停并从原位置续播；Esc 或“停止”按钮显式停止，之后从第一个点重新播放。
- **读趋势和数值**：规则生成摘要，支持浏览器语音及读屏用的 `aria-live`；导览使用精简播报。
- **30 秒体验**：点击“开始体验”，依次听开场、闭眼模式下的整条数据和短摘要；运行中按钮变为“停止体验”，再次激活只停止，不自动重开；任意键也可中断。
- **查看替代信息**：数据表、最高点/最低点跳转、键盘帮助。
- **使用自己的数据**：按行粘贴“标签,数值”，逐行报错并限制最多 200 点；可勾选“首行是表头”显式跳过第一行。
- **调整体验**：三档播放速度、浏览器语音开关、参考音开关、“上一个/下一个”触屏按钮；偏好自动保存在本机。
- **测试**：Vitest 覆盖解析、统计、摘要、声音调度、暂停续播、语音取消和快捷键逻辑（99 项）；6 项 Playwright 测试在真实 Chrome 中回归表单表头选择、导览停止和长按快捷键。

**未实现**：截图识别后端、完整 CSV 文件上传、多系列图表。截图按钮当前禁用，接口代码仅为预留。

## 快速开始

本仓库使用 Node.js 22.12+（22 系列）和 npm；依赖由 `package-lock.json` 锁定。

```bash
git clone https://github.com/youngcarl/hear-chart-app.git
cd hear-chart-app
npm ci
npm run dev
```

```bash
npm test            # Vitest 单测
npm run test:e2e    # Playwright 浏览器测试（使用本机 Chrome；需先安装依赖）
npm run build       # TypeScript 严格检查 + 生产打包
npm run preview     # 预览 dist/，实际地址以终端输出为准
```

核心功能无需 API Key、数据库或模型服务。浏览器音频通常需要先点击或按键；中文语音可用性及是否联网取决于系统、浏览器和所选语音，不能保证完全离线朗读。

### 粘贴数据示例

```text
周一,12
周二,18
周三,15
周四,24
周五,21
```

标签可以带文字，也可以纯数字（如 Excel 年份列 `2024,86`）。当前为简单的逐行文本解析，不是支持引号和复杂字段的完整 CSV 解析器。数字必须完整合法（`Infinity`、`12abc` 会被拒绝）；行尾分隔符后缺值、首行坏值都会按原始行号报错（表单显示全部错误行）；只有勾选“首行是表头”才跳过第一个非空行，未勾选时首行与其他行同样校验（包括 `2024,x` 和常见表头词），任何错误都会阻止生成图表；最多 200 个点。偏好设置保存在本机 `localStorage`，自定义数据仅存在于当前页面，刷新后需要重新添加。

## 键盘操作

| 按键 | 操作 |
| --- | --- |
| ← / → | 上一个 / 下一个数据点 |
| ↑ / ↓ | 最高点 / 最低点 |
| Home / End | 第一个 / 最后一个点 |
| 空格 | 播放整条 / 暂停 / 从暂停处继续 |
| Esc | 停止播放（从头重播）；闭眼模式内退出模式 |
| S / R / H | 朗读摘要 / 当前点 / 帮助 |
| P | 重听最低音和最高音 |
| T | 开关浏览器语音 |
| B | 进入 / 退出黑幕闭眼模式 |
| 1–4 | 切换已有图表（第 4 项需先添加自定义数据） |

这些快捷键只在图表获得焦点时生效：方向键不会滚动页面且可长按导航，长按空格不会重复切换播放或滚动页面，Tab 可正常离开图表；焦点在普通按钮、输入框或页面空白处时不会误触。闭眼模式下 Esc 在任意位置都能退出。使用读屏软件时可关闭“浏览器语音朗读”以减少重复播报。闭眼模式提供“退出闭眼模式”按钮，可触摸操作。

## 技术结构

| 模块 | 职责 |
| --- | --- |
| React 19 + TypeScript | 页面状态和交互 |
| Vite 7 | 开发服务与静态构建 |
| Web Audio API | 音高、声像及播放 |
| SpeechSynthesis + aria-live | 浏览器朗读及读屏提示 |
| 手写 SVG + CSS | 图表高亮和布局 |

- `src/App.tsx`：数据选择、当前点、快捷键、播放状态机、导览和页面状态。
- `src/components/`：SVG 图表、数据表、设置、数据输入和首次运行对话框。
- `src/lib/analyze.ts`、`parse.ts`：规则分析、摘要和输入解析。
- `src/lib/sonify.ts`、`speech.ts`：声音合成、语音和音色提示。
- `src/lib/settings.ts`、`strings.ts`、`tour.ts`：偏好持久化、集中文案和可中断导览。
- `src/lib/extract.ts`：默认关闭的 `/api/extract-chart` 请求预留；仓库没有对应后端。

偏好设置写入本机 `localStorage`，自定义数据和当前查看状态只存在于页面内存。源码没有账户系统、数据库或分析埋点。仓库公开不等于网站已部署；静态构建输出为 `dist/`，采用相对资源路径。

# 听见图表 · Hear Chart

**用声音探索图表，让数据不只被看见。**

面向视障、低视力学生的图表声音化前端原型：将数值转换为音高、将数据顺序映射到左右声道，配合键盘逐点浏览、语音朗读和规则摘要，帮助用户理解折线图与柱状图。

> 当前版本：**v0.1 原型**。初始代码和方案由 Claude 辅助产出，本仓库整理了源码、项目定位和后续计划。样例数据均为虚构；尚未完成真实读屏用户验收，不代表已达到无障碍合规标准。

## 当前能做什么

- **听数据点**：方向键、Home / End 或点击图表，浏览每个标签和数值。
- **听整体变化**：折线连续滑音，柱状图逐点发声；数值对应约 220–880 Hz，顺序对应左右声道。
- **读趋势和数值**：规则生成摘要，支持浏览器语音及读屏用的 `aria-live`。
- **查看替代信息**：提供数据表、最高点/最低点跳转和键盘帮助。
- **使用自己的数据**：按行粘贴“标签,数值”；支持一组可替换的自定义数据。
- **调整体验**：三档播放速度、浏览器语音开关和键盘控制的黑幕“闭眼模式”。

**未实现**：截图识别后端、完整 CSV 文件上传、暂停续播、移动端触摸手势、多系列图表和设置持久化。截图按钮当前禁用，接口代码仅为预留。

## 快速开始

本仓库使用 Node.js 22.12+（22 系列）和 npm；依赖由 `package-lock.json` 锁定。

```bash
git clone https://github.com/youngcarl/hear-chart-app.git
cd hear-chart-app
npm ci
npm run dev
```

```bash
npm run build       # TypeScript 严格检查 + 生产打包
npm run preview     # 预览 dist/，实际地址以终端输出为准
```

核心功能无需 API Key、数据库或模型服务。浏览器音频通常需要先点击或按键；中文语音可用性及是否联网取决于系统、浏览器和所选语音，不能保证完全离线朗读。

### 粘贴数据示例

```text
周一,12
周二,18
周三,15
周四,24
周五,21
```

当前为简单的逐行文本解析，不是支持引号和复杂字段的完整 CSV 解析器。刷新页面后，自定义数据和设置不会保留。

## 键盘操作

| 按键 | 操作 |
| --- | --- |
| ← / → | 上一个 / 下一个数据点 |
| ↑ / ↓ | 最高点 / 最低点 |
| Home / End | 第一个 / 最后一个点 |
| 空格 | 从头播放整条数据（不是暂停/续播） |
| S / R / H | 朗读摘要 / 当前点 / 帮助 |
| B / Esc | 进入 / 退出黑幕闭眼模式 |
| 1–4 | 切换已有图表（第 4 项需先添加自定义数据） |

输入框、文本框和选择框内不触发图表快捷键；Esc 仍可退出闭眼模式。使用读屏软件时可关闭“浏览器语音朗读”以减少重复播报。闭眼模式目前没有触屏退出按钮，不建议在仅触屏设备上开启。

## 技术结构

| 模块 | 职责 |
| --- | --- |
| React 19 + TypeScript | 页面状态和交互 |
| Vite 7 | 开发服务与静态构建 |
| Web Audio API | 音高、声像及播放 |
| SpeechSynthesis + aria-live | 浏览器朗读及读屏提示 |
| 手写 SVG + CSS | 图表高亮和布局 |

- `src/App.tsx`：数据选择、当前点、快捷键和页面状态。
- `src/components/`：SVG 图表、数据表、设置及数据输入。
- `src/lib/analyze.ts`、`parse.ts`：规则分析和输入解析。
- `src/lib/sonify.ts`、`speech.ts`：声音合成和语音。
- `src/lib/extract.ts`：默认关闭的 `/api/extract-chart` 请求预留；仓库没有对应后端。

当前图表与设置保存在页面内存中，源码没有账户系统、数据库或分析埋点。仓库公开不等于网站已部署；静态构建输出为 `dist/`，采用相对资源路径。

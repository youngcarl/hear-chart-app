# 改进路线图

以下是对 Claude 两份方案与源码审阅结果的归纳，**不是已实现清单**。本次工作只整理公开仓库，不实施完整产品升级。

## P0：先让核心体验可靠

- [ ] 修正常量序列的趋势判断，严格拒绝非有限数值和混杂文本。
- [ ] 修正全负柱状图坐标范围，覆盖零值、负值、单点和相同数值等边界。
- [ ] 增加解析、统计及声音映射的纯函数测试。
- [ ] 将快捷键约束到合适焦点范围，检查与读屏快捷键的冲突。
- [ ] 首次明确选择读屏或浏览器语音，降低双重播报。
- [ ] 加入暂停、续播、停止及播放完成提示。
- [ ] 切换图表时取消旧播放及延迟朗读任务。
- [ ] 为闭眼模式提供明确、可触摸的退出入口，并验证焦点顺序。
- [ ] 增加可随时停止的短导览，不以固定等待时间冒充朗读完成。
- [ ] 实测 NVDA / VoiceOver 等读屏环境和移动端音频启动行为。

## P1：验证听觉理解和日常可用性

- [ ] 增加参考音、极值和零点提示，避免只靠音高猜数值。
- [ ] 增加“上一点 / 下一点”按钮与触摸浏览。
- [ ] 优化摘要、数字格式和播报粒度。
- [ ] 持久化偏好设置；保持用户数据处理方式清晰可控。
- [ ] 在交互稳定后拆分状态、快捷键、播放等 hooks。
- [ ] 检查颜色对比、200% 缩放、键盘焦点和系统明暗主题。
- [ ] 邀请真实读屏用户完成读图任务，记录失败环节并迭代。

## P2：在核心可靠后扩展输入

- [ ] CSV 文件导入：完整处理编码、字段、校验及错误提示。
- [ ] 截图识别：后端模型调用、限额、失败处理、数据说明及人工核对。
- [ ] 多系列图表：音色区分、系列切换及对比阅读。
- [ ] 评估散点图、饼图的听觉表示，而非仅复用折线映射。

截图识别若接入，模型凭据必须放在服务端环境变量中，不进入前端或仓库；当前没有可用识别服务。

## 参赛准备（待核实）

- [ ] 核对主办方当前赛道、报名资格、期限和提交要求。
- [ ] 如需特定工具开发或部署记录，保留真实过程证据。
- [ ] 准备演示：样例选择 → 听整体 → 找极值 → 对照数据表。
- [ ] 清楚声明 AI 辅助、已完成范围和已知限制。

不以旧帖子数量推断竞争程度，不承诺入围或奖金。

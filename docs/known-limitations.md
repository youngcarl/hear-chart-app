# 已知问题与测试边界

以下问题来自源码静态审阅；本次公开整理未修改原型业务逻辑。

## 已发现的问题

| 问题 | 涉及模块 | 影响 |
| --- | --- | --- |
| 所有值相同的折线可能被描述为“整体下降” | analyze.ts | 趋势摘要不准确 |
| parseFloat 可接受 Infinity、12abc 等输入 | parse.ts | 非有限数可能使绘图或发声异常，尾随文本未严格校验 |
| 全负柱状图没有保证纵轴范围包含零 | ChartView.tsx | 零基线可能超出绘图区 |
| 无暂停/恢复，切图未清除所有延迟单点朗读 | App.tsx / sonify.ts | 播放流程不完整，可能短暂播报旧数据 |
| 闭眼模式只是视觉黑幕，没有触屏退出按钮和完整焦点管理 | App.tsx | 仅触屏设备或部分读屏场景存在操作阻碍 |
| 输入没有明确的数据量上限 | parse.ts | 大量数据的性能和可操作性未验证 |

## 功能边界

- 自定义数据和设置只存在于当前页面内存，刷新丢失。
- 浏览器语音不保证离线或始终有中文声音。
- 截图识别默认关闭，没有后端、上传流程或识别验证。
- 没有完整 CSV 文件解析、多系列或触摸手势。
- 核心图表处理代码无账户、数据库或埋点；系统/浏览器语音的数据处理仍取决于所用环境。

## 尚未执行的验收

- NVDA、VoiceOver、TalkBack 和真实视障用户任务测试。
- WCAG 合规审计、色彩对比与 200% 缩放验收。
- 不同浏览器与手机上的实际音频、焦点及快捷键检查。
- 截图识别、参赛部署和线上应用端到端测试。

类型检查和构建通过不代表这些项目通过，也不证明声音输出或无障碍体验符合预期。

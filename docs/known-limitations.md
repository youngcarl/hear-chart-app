# 已知问题与测试边界

第一轮迭代（2026-11-18）修复了此前静态审阅发现的表格中的主要问题。本页区分“已修复”“仍然存在”和“尚未验收”。

## 本轮已修复

| 原问题 | 处理方式 |
| --- | --- |
| 所有值相同的折线可能被描述为“整体下降” | 全距为 0 单独处理；起伏不足量级 2% 判为基本持平 |
| parseFloat 可接受 Infinity、12abc 等输入 | 改用完整数字正则；非有限数和尾随文本逐行报错；首个非数字行按表头跳过 |
| 全负柱状图没有保证纵轴范围包含零 | 坐标范围强制包含 0，负值向下绘制，高度取绝对值 |
| 无停止、切图未清除延迟朗读 | 空格播放/停止；播放令牌作废旧回调；切图、加数据、导览中断都会停止声音和定时器 |
| 闭眼模式没有触屏退出和焦点管理 | 增加“退出闭眼模式”按钮；模式内 Tab 不离开；Esc 或任意指针操作可退出 |
| 输入没有数据量上限 | 最多 200 个点，超出时提示并停止读取 |
| 图表快捷键全局生效、与表单冲突 | 快捷键绑定在图表焦点内；输入框内不触发；Tab 可离开图表 |
| 首次运行不区分读屏与浏览器语音 | 首次运行对话框强制二选一，结果持久化 |
| 设置刷新后丢失 | 偏好（语音、语速、参考音、上次图表）写入 localStorage，读取时校验 |

## 仍然存在

- **自定义数据不持久化**：刷新后需要重新粘贴；当前查看的图表 id 会恢复，但若自定义数据不存在会回退。
- **暂停状态不跨切图保留**：切图、添加数据或导览会按预期清空进度。
- **浏览器回归只覆盖 Chrome**：Playwright 使用系统 Chrome，未跑 Firefox/Safari；真实读屏仍待验收。
- **读屏与浏览器语音可能重复**：关闭浏览器语音可避免；首次运行对话框只是引导。
- **中文语音依赖系统**：没有可用语音时静默，只保留 aria-live 和数据表。
- **单系列、固定音阶**：数值映射为 220–880 Hz，极大或极小范围的数据会压缩差异。
- **触屏拖动未在真机验证**：Pointer Events 代码已实现，但只在桌面浏览器检查。
- **200% 缩放、色彩对比、明暗主题未系统审计**。

## 功能边界

- 截图识别默认关闭，没有后端、上传流程或识别验证。
- 没有完整 CSV 文件解析、多系列或饼图/散点图。
- 核心图表处理代码无账户、数据库或埋点；朗读时文本会交给系统/浏览器语音，其数据处理取决于所用环境。

## 尚未执行的验收

- NVDA、VoiceOver、TalkBack 和真实视障用户任务测试。
- WCAG 合规审计、色彩对比与 200% 缩放验收。
- 不同浏览器与手机上的实际音频、焦点及快捷键检查；本机无头浏览器无法确认听到的声音质量。
- 截图识别、参赛部署和线上应用端到端测试。

类型检查、单元测试和构建通过不代表这些项目通过，也不证明声音输出或无障碍体验符合预期。

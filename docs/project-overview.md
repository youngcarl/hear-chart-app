# 项目归纳

## 一句话定位

听见图表是给视障、低视力学生使用的图表声音化原型：通过“听趋势、听单点、读摘要、查数据表”理解单系列折线图和柱状图。

## 目标用户与典型流程

目标用户是需要理解课堂、报告或学习资料中简单图表的视障及低视力学生。这是设计假设，仍需真实用户验证。

1. 选择虚构样例，或粘贴标签和数值。
2. 播放整个系列，感受整体变化。
3. 用键盘逐点探索，听取标签、数值和变化。
4. 跳到最高或最低点，朗读摘要或查看数据表。

图表声音化并不是把图片直接读出来。当前输入必须已有结构化数据；截图识别尚未接入。

## 已有交付

- React / TypeScript / Vite 前端原型，58 项纯函数单元测试。
- 3 组虚构样例及 1 组可替换的自定义数据。
- 单系列折线、柱状图，SVG 可视化和数据表。
- Web Audio 音高与声道映射、单点与整条播放、参考音和极值提示。
- 可停止播放、30 秒导览、闭眼模式与触摸按钮。
- 规则统计与短摘要、浏览器语音、读屏提示及焦点内快捷键。
- 偏好设置本地持久化；默认关闭的截图识别请求接口定义。

没有模型推理后端、账户、数据库、在线服务、真实用户测试记录或参赛提交记录。规则摘要不是大模型分析，原方案也不能证明 Qoder 开发过程已经完成。

## 如何衡量下一步是否有用

优先验证用户能否不依赖视觉完成任务，而不是先增加功能数量：

- 仅键盘能否完成选图、播放、找最高值、逐点比较和退出模式？
- 读屏提示是否清楚且不重复，是否与系统快捷键冲突？
- 用户能否说出整体趋势、极值和一个关键变化？
- 出错或不支持语音时，是否仍能通过数据表和提示完成任务？

这些是后续验收建议，不是已完成的测试结果。

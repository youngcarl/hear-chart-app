## 最新修复验证（2026-11-18，显式校验与停止语义）

- **显式表头**：Chrome 表单输入 `周一,坏行\n9月,86\n10月,92` 并勾选“首行是表头”，生成图表的数据表为 9月/10月且无错误；不勾选时输入 `2024,x\n2025,20\n2026,30`，报第 1 行错误并保留原图表，不生成缺行图表。单测保留中英文/单列常见表头覆盖，并验证勾选后只跳过第一个非空行、后续坏行仍保留原始行号。
- **导览停止**：开场中分别以鼠标点击和仅 DOM `click()` 激活“停止体验”；另在闭眼播放阶段以仅 `click()` 停止。三条路径均回到“开始体验”、退出闭眼模式、停止播放并显示结束提示；继续观察 3.5 秒，监测 `aria-live` 没有再次开场且保持空闲。鼠标测试在开场阶段进行，不声称鼠标可穿透闭眼遮罩点击原按钮。
- **空格长按**：单测与 Chrome 测试均确认重复空格被 `preventDefault` 且不再切换播放，方向键重复仍连续导航。浏览器测试检查取消默认行为，不以合成键盘事件声称实际测得页面滚动距离。
- 浏览器测试命令：`npm run test:e2e`（Playwright + 系统 Chrome；自动启动 Vite 开发服务）。本轮未改写音频挂起/恢复或暂停后切图逻辑。
- 下方第三轮及更早内容为当时验证记录；旧版自动表头与导览重启行为已被本节覆盖。

## 第三轮修复验证（2026-11-18，issue #1 / #5 / #6）

- **首行校验（#1）**：`周一,坏行`、`周二,Infinity`、`周三,12abc`、`周四,` 同时提交时显示 5 条提示，分别带第 1–4 行号；`周一,坏行` 不再被当表头。`月份,销量`、`label,value`、单列 `销量` 等明确表头仍可跳过，`2024,86` 纯数字标签正常。
- **表单错误（#1）**：不再截断前 3 条，上述 5 条全部显示在 `role="alert"` 区域。
- **暂停/续播（#5）**：4 个点、慢速档，空格播放 → 约 0.7 秒暂停（按钮变“继续”，读出“已暂停，当前是B，2”）→ 等待 0.9 秒仍保持暂停 → 空格续播 → 自然结束读出“播放结束”；再次空格从 A 点重新开始；Esc 停止后按钮禁用并读出“已停止播放……再按空格从头播放”。
- **快捷键范围（#6）**：焦点在“播放整条”按钮时模拟 B、T、1、→、S，均未阻止默认行为且图表未变化；焦点进入图表后 2 切图、T 开关语音、B 进入闭眼模式均生效。
- **导览按钮**：30 秒体验启动后按钮变“体验中…按任意键停止，点击可重开”，约 14 秒进入短摘要、27 秒完成并自动退出闭眼模式；再次启动后按任意键可中断并恢复按钮。

## 第二轮修复验证（2026-11-18）

- **组合键**：图表聚焦时模拟 Ctrl+R、Ctrl+S、Ctrl+P、Meta+R、Alt+←，均未调用 `preventDefault`、未触发图表动作；裸方向键正常拦截；输入法组合状态（`isComposing`）不抢方向键。
- **解析**：`2024,` 缺值报“第 1 行……末尾的分隔符后缺少数值。”且不生成数据点；首行 `12abc` 正常报错；`2024,86` 纯数字标签仍可用；尾随 Tab、连续分隔符、分隔符两侧空格均有测试覆盖。
- **语音关闭**：长摘要朗读中按 T，`speechSynthesis.cancel` 被调用且不再启动旧摘要；逐点朗读的 220ms 等待期间关闭，不再播出旧数值；`aria-live` 仍保留“浏览器语音已关闭”提示。
- **柱状图摘要**：`[-5,10]` 输出“含负值，净合计 5元”，不再出现“最高一项占 200%”；全负、零合计、全零均有测试。
- **播放完成时机**：慢速三档单测覆盖 0.2/0.32/0.5 秒；页面实测 3 个点、0.5 秒、关闭参考音时，“播放结束”在 1.54 秒出现（修复前约 1.35 秒）。
- 此前一轮的焦点、闭眼模式 Tab 循环、1–4 切图、空格播放/停止、负数柱状图、10 亿量级刻度、设置持久化仍复验通过。

## 浏览器冒烟检查（Chromium，localhost）

- 首次运行对话框：默认焦点落在“是，我在用读屏软件”；Tab 在两个按钮间循环；选择结果持久化；关闭后焦点回到图表。
- 图表焦点：点击图表后焦点进入图表；方向键逐点播报；Tab 可离开到“上一个”按钮。
- 闭眼模式：B 进入、Esc 退出并回到图表；Tab 在图表和“退出闭眼模式”之间循环。
- 30 秒体验：精简摘要，约 26 秒完成并自动退出闭眼模式。
- 设置：T 切换浏览器语音并写入 localStorage；刷新后语音开关、语速、参考音、上次图表恢复。
- 输入保护：文本框内按 2 不会切换图表，字符正常输入。
